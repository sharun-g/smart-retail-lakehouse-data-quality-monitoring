# Smart Retail Lakehouse with Automated Data Quality Monitoring

A modern Data Engineering project that implements an end-to-end Lakehouse architecture using Databricks, PySpark, Delta Lake, and AWS SNS.

The project ingests raw retail data, performs multi-stage ETL processing using the Medallion Architecture (Bronze, Silver, Gold), validates data quality, generates analytical datasets, and sends automated pipeline execution reports via Amazon SNS.

---

## Features

- Medallion Lakehouse Architecture
- PySpark ETL Pipelines
- Delta Lake Storage
- Automated Data Quality Validation
- Gold Layer Business Analytics
- AWS SNS Email Notifications
- Master Pipeline Orchestration
- End-to-End Data Engineering Workflow
